# Security Policy

## Supported versions

Earmark is a single-page web app with one current version: whatever is
live at https://xolixia.github.io/earmark/. Fixes are made there, so
there are no older versions to patch.

## How your data is handled

Earmark has no server and no accounts. Entries are saved in your own
browser's local storage and are never sent to me, GitHub, or anyone
else. Clearing your browser's site data deletes them.

## Reporting a vulnerability

If you find a security problem, please report it privately through the
**Security** tab of this repository ("Report a vulnerability") rather
than opening a public issue. I'll reply as soon as I can and let you
know whether and how it will be fixed.
